6. Faculty table  
   1. Faculty Transitions \-   
      The provost assistant will cc IR on tenure and promotion letters. Store these in [Institutional Research/Institutional Research Department Data/Faculty/Faculty\_Transitions/AY](https://drive.google.com/drive/folders/1v2gBRcxv3oLsC9BJIsLZ994Fw-oEShV8?usp=drive_link). These are critical in building / maintaining the [Faculty\_AcademicYear\_Observation](https://docs.google.com/spreadsheets/d/19QlwU4t6zL5U5j7rwwd4EvC4FOGkJK9ehcTvzgG5SwE/edit?usp=sharing) file.  We hope to be able to use Oracle exclusively from AY 2026 and on, but even when that works, we will need historical data from this file.  
      1. There is a set of \*.mdb / \*.accdb files from the ‘old days’ that contain faculty HR information.   
      2. Beginning of year: The annual ‘Sabbatic’ / ‘Sabbatic and Departures’ file that is sent out by the provost’s assistant should be sorted in [Institutional Research/Institutional Research Department Data/Faculty/Faculty\_Transitions](https://drive.google.com/drive/folders/1v2gBRcxv3oLsC9BJIsLZ994Fw-oEShV8?usp=drive_link).  When that comes out, copy all the faculty from the previous year in [Faculty\_AcademicYear\_Observation](https://docs.google.com/spreadsheets/d/19QlwU4t6zL5U5j7rwwd4EvC4FOGkJK9ehcTvzgG5SwE/edit?usp=sharing) file and paste new rows at the bottom.  Update the year. Then go through the ‘Sabbatic’ file and delete anyone who has left, add new, and update the ‘Status’ column for the new sabbaticals / returning from sabbaticals.

   

7. [Department\_program\_prefix](https://docs.google.com/spreadsheets/d/1C41_DI_PbEGPkjuIT7xMnmPR24azNSohTR6JbNY23TM/edit?usp=sharing)  
   1. ‘Departments’ aren’t a thing in Colleague.  Course prefixes exist, as do majors and minors, but ‘departments’ do not. The table linked here is a tidy set of annual observations that map the programs and prefixes to the department.   
   2. As students may graduate with a program years after the program was disbanded, there are a few ‘pseudo’ records included, to allow mappings for students that outstrip the changes to a program or department.  
   3. Oracle *should* be set up to have HR departments map to Academic departments, alleviating the need to maintain this file.
